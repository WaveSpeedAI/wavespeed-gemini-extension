# WaveSpeed

The `wavespeed` CLI is available for AI media generation (image, video, audio, 3D)
via the WaveSpeed platform. When a task calls for creating, editing, animating,
upscaling, or transforming media, use the bundled `wavespeed` skill — it covers
the find → inspect → run pattern, local-file upload, and price checks.

If `wavespeed` is not installed: `npm install -g @wavespeed/cli`, then
`wavespeed login` (never ask the user to paste an API key into the chat).
